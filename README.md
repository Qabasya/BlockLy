# BlockLy — конструктор кода по блокам

Учебное приложение для мастер-классов по программированию и электронике.
Ученик собирает программу из перемешанных строк-блоков, при необходимости
вписывает значения в поля, проверяет себя и копирует готовый код в Arduino IDE
или PyCharm.

Приложение работает без интернета и без установки: это папка с файлами, которая
открывается двойным кликом в Chrome или Edge. Об ученике приложение ничего не
помнит — каждый следующий начинает с нуля, поэтому за одним компьютером за день
могут смениться несколько человек.

## 1. Подготовка компьютера

1. Скопируйте папку проекта целиком на ноутбук, например в
   `Документы/BlockLy`. Папка должна лежать **внутри** «Документов»,
   «Рабочего стола» или «Загрузок», а не быть одной из них: сами эти системные
   папки браузер выбрать не разрешит.
2. Установите актуальный Chrome или Edge. Другие браузеры не подходят: запись
   файлов из админки работает только в них.
3. Откройте `index.html` двойным кликом. Если файл открылся не в том браузере,
   нажмите на нём правой кнопкой → «Открыть с помощью» → Chrome/Edge.
4. Экран рассчитан на ноутбук 1920×1080 с масштабом 150 %. На другом разрешении
   всё тоже работает, но вид выверен именно под этот размер.

Интернет не нужен ни на одном этапе.

## 2. Вход в администрирование

1. На главном экране нажмите **«Администрирование»** в правом верхнем углу.
2. Введите пароль. По умолчанию — `mk2026`.

Пароль лежит открытым текстом в `js/config.js` (`adminPassword`) и меняется
там же в любом текстовом редакторе. Это не защита, а ширма: он нужен, чтобы
ученик случайно не зашёл в редактор.

Чтобы выйти из админки, нажмите **«Выйти»**. Клик по логотипу тоже возвращает
к списку мастер-классов.

## 3. Подключение папки проекта

Админка сохраняет мастер-классы прямо в файлы проекта. Для этого браузеру один
раз нужно разрешение на запись в папку.

1. В шапке админки нажмите **«Подключить папку»**.
2. В системном окне выберите **саму папку проекта** — ту, где лежат `index.html`
   и папка `workshops`.
3. Разрешите браузеру изменять файлы.

Браузер запоминает выбор, и после перезагрузки страницы повторять его обычно не
нужно. Если разрешение слетело, в шапке снова появится «Подключить папку» —
хватит одного клика.

Пока папка не подключена, кнопки **«Сохранить»** и **«Посмотреть как ученик»**
неактивны. Если выбрать не ту папку, приложение объяснит, что в ней нет
`index.html` и `workshops`.

## 4. Создание мастер-класса

Справа в админке — список мастер-классов. Его можно свернуть стрелкой в
заголовке.

- Чтобы **открыть** мастер-класс, кликните по нему в списке.
- Чтобы **создать** новый, нажмите **«+ Мастер-класс»** внизу списка.

У нового мастер-класса заполните:

- **Название** — например, `МК-5: Светофор`. Оно видно на карточке главного
  экрана и в шапке у ученика. Из названия строится имя файла
  (`workshops/mk-5-svetofor.js`), после первого сохранения оно не меняется.
- **Язык** — Arduino или Python. От языка зависят цвет бейджа на карточке и то,
  какие комментарии убираются из кода (см. раздел 6). На разбор структуры
  программы язык не влияет.

## 5. Этапы

Мастер-класс состоит из этапов. Этап — отдельная законченная программа,
например «Лента белым цветом», «Бегущий огонёк», «Плавная радуга». Этапы между
собой не связаны, ученик переключает их в выпадающем списке в шапке.

- **«+ Этап»** добавляет пустой этап в конец и сразу открывает его.
- **Название этапа** вписывается в поле под рядом кнопок-этапов.
- **«Дублировать этап»** ставит копию текущего этапа сразу за ним: код всех
  фрагментов и описания шагов копируются, к названию добавляется «(копия)».
  Удобно, когда следующий этап отличается от предыдущего парой строк: поменяйте
  их в копии, разберите на шаги заново — описания неизменённых строк останутся.
- **«Удалить этап»** спрашивает подтверждение и показывает, что пропадёт.
  Единственный этап удалить нельзя.

Порядок этапов поменять нельзя, поэтому создавайте их в нужной
последовательности. Дублирование помогает: копия встаёт сразу за исходным
этапом.

## 6. Фрагменты: вставляем код

Внутри этапа есть два режима: **«Фрагменты»** (правка кода) и **«Шаги»**
(описания). Сначала — фрагменты.

**Фрагмент** — кусок программы, который вы как автор считаете единым целым:
объявления, `setup`, `loop` и т. п. Порядок фрагментов для ученика жёстко
задан. В готовом коде, который скопирует ученик, фрагменты разделены пустой
строкой.

### Как вставить код

1. Вставьте **рабочий** код в поле фрагмента. Каждая строка кода станет
   блоком, который ученик будет перетаскивать.
2. **«+ Фрагмент»** добавляет следующую карточку.
3. Стрелки **↑↓** в заголовке карточки меняют порядок фрагментов, корзина
   удаляет фрагмент после подтверждения.
4. Свёрнутая карточка показывает первую строку и число строк — кликните стрелку
   справа, чтобы развернуть.

Под кодом видна сводка: сколько получилось блоков, хвостов, какой шаг отступа
и сколько полей ввода. Сверяйтесь с ней, если не уверены, как разберётся код.

### Отступы решают всё

Приложение не разбирает синтаксис языка. Вложенность программы оно берёт
**только из отступов**:

- строка, под которой идут строки с бо́льшим отступом, становится
  **открывающим блоком** (блок в форме буквы «С» — у ученика внутри неё
  появляются пустые слоты);
- строка только из закрывающих скобок и знаков (`}`, `});`, `)` и т. п.) —
  это **хвост**. Он встаёт на место сам, ученик его не таскает и не проверяет;
- `} else {` и `elif x:` работают сами собой — как обычные открывающие блоки.

Поэтому код должен быть аккуратно выровнен. Кнопка **«Выровнять отступы»**
убирает табы, приводит отступы к шагу языка (Arduino — 2 пробела, Python — 4)
и раскладывает строки по глубине. Нажимайте её после каждой вставки кода
из другого места.

### Переключатель «Строки можно менять местами»

Включите его, если строки фрагмента **верхнего уровня** можно ставить в любом
порядке — например, несколько `#define` подряд. Тогда любой их порядок у
ученика засчитается как верный. Тела вложенных блоков переключатель не
затрагивает: они всегда проверяются по порядку.

### Комментарии

Комментарии при разборе удаляются: в Arduino — всё после `//`, в Python — всё
после `#`. Внутри кавычек ничего не трогается, `#define`/`#include` в Arduino и
`//` (деление) в Python тоже. Пояснения к строкам пишите в описания шагов.

### Одинаковые строки

Две одинаковые строки (например, `FastLED.show();` в разных местах) у ученика
взаимозаменяемы — это не ошибка. Похожие строки, отличающиеся одним символом
(`leds[0]` и `leds[1]`), приложение само подсветит ученику, чтобы он увидел
разницу.

## 7. Поля ввода

В строку кода можно вставить поле, которое ученик заполнит сам. Разметка —
двойные фигурные скобки прямо в коде фрагмента. Памятка со всеми видами полей
открывается над фрагментами: **«Памятка: поля ввода в коде»**.

| Как написать | Что видит ученик | Что засчитывается |
|---|---|---|
| `CRGB::{{White\|Red\|Blue}}` | выпадающий список, варианты перемешаны | любой вариант из списка |
| `CRGB::{{White}}` | пустое поле для ввода | только `White` |
| `fill_solid{{(leds, NUM_LEDS, CRGB::White)}};` | поле для длинного куска строки | текст целиком |

Правила проверки полей со свободным вводом:

- **регистр учитывается**: `white` вместо `White` не скомпилируется в Arduino
  IDE. Если ошибка только в регистре, ученик увидит «проверь заглавные»;
- пробелы по краям и лишние пробелы внутри не важны: `(leds,NUM_LEDS)` =
  `(leds, NUM_LEDS)`; но пробел между словами важен: `int x` ≠ `intx`;
- ширина поля — по длине ответа плюс два символа, у списка — по самому
  длинному варианту.

Ещё:

- в одной строке может быть несколько полей: `leds[{{0}}] = CRGB::{{Red|Blue}};`;
- внутри значения нельзя писать `|` и `}}`;
- незаполненное поле не засчитывается, ученик увидит «заполни поле».

Сложность этапа регулируется именно полями: больше полей и длиннее куски —
сложнее.

## 8. Шаги: описания для ученика

Когда код вставлен, нажмите **«Разобрать на шаги →»** на закреплённой панели
внизу. Код разбирается на блоки, и карточки фрагментов сменяются списком строк.

У каждой строки есть метка «Шаг N», отступ по глубине, пометка фрагмента и поле
описания. Опишите, **что должен сделать ученик** на этом шаге, например
«Подключите библиотеку FastLED». Ученик увидит описание под шапкой, когда эта
строка будет следующей по порядку.

- Строка без описания подсвечивается предупреждением. Это допустимо: ученик
  просто увидит пустой шаг.
- Хвостам (`}`) описания не нужны, их в списке нет.
- **«← К фрагментам»** возвращает к правке кода, описания при этом не
  пропадают.

### Переход между фрагментами и шагами

Между «Фрагментами» и «Шагами» можно переходить сколько угодно — описания
никуда не денутся:

- поправили код → **«Разобрать на шаги →»**. Если вы только добавляли или
  переставляли строки, шаги откроются сразу, все описания на месте, у новых
  строк описание пустое;
- выбранный режим сохраняется при переключении этапа и мастер-класса. Нужно
  скопировать описание из прошлого этапа — откройте его кнопкой-этапом, оставаясь
  в «Шагах», скопируйте текст и вернитесь.

Описания привязаны к тексту строки. Если строку изменить или удалить, её
описание пропадёт — перед этим появится окно с подсчётом: сколько описаний
сохранится, сколько пропадёт и сколько строк новых. Можно нажать «Отмена» и
сначала скопировать нужные описания. Если у этапа описания пропали бы, при
переходе на него откроются «Фрагменты».

## 9. Сохранение и просмотр глазами ученика

- В шапке видно состояние: **«Есть несохранённые изменения»** или
  **«Сохранено»**.
- **«Сохранить»** записывает файл мастер-класса в `workshops/`. Новый
  мастер-класс ещё и подключается строкой в `index.html` — вручную ничего
  править не нужно. Без названия или языка сохранить нельзя: приложение
  подскажет, чего не хватает.
- **«Посмотреть как ученик»** открывает экран ученика с этим мастер-классом на
  текущем этапе. Кнопка работает только когда всё сохранено: ученик видит
  только сохранённые версии.
- Если уйти с несохранёнными изменениями (выбрать другой мастер-класс, нажать
  «+ Мастер-класс» или «Выйти»), приложение спросит, выйти ли без сохранения.

Если браузер не умеет записывать в папку, «Сохранить» скачает файл. Положите
его в папку `workshops` проекта. Для нового мастер-класса добавьте ещё в
`index.html` строку, которую покажет приложение, рядом с другими
`<script src="workshops/…">`.

**Перед занятием** обязательно пройдите каждый этап сами через «Посмотреть как
ученик», скопируйте код и прошейте плату (или запустите программу). Так вы
убедитесь, что код рабочий и разбит на блоки так, как задумано.

## 10. Проведение занятия

### Запуск

Откройте `index.html`. Ученик выбирает карточку мастер-класса на главном
экране, этап — в выпадающем списке в шапке.

### Что видит ученик

- Под шапкой — **«Шаг N из M»** и описание следующей строки, которую нужно
  поставить.
- Слева — **«Твоя программа»**: пустые слоты верхнего уровня. Когда ученик
  ставит открывающий блок (`void loop() {`), под ним раскрываются слоты его тела
  и серый хвост. Структура открывается по мере сборки, а не выдаётся вперёд.
- Справа — **«Блоки»**: перемешанная палитра и счётчик «осталось блоков: N».

### Как собирать

- **Перетаскиванием** мышью или тачпадом: блок из палитры — в слот. Блок
  можно переставить в другой слот или вернуть, перетащив обратно в палитру.
  Если убрать открывающий блок, его содержимое вернётся в палитру.
- **С клавиатуры**, если мышь недоступна: Tab — по блокам, Enter — поставить в
  первый свободный слот или вернуть, стрелки ↑↓ — переставить.
- В поля ввода значения вписываются или выбираются прямо в блоке.

### Подсказка

Кнопка с лампочкой в шапке подсвечивает зелёным **один** следующий нужный блок
в палитре. Подсветка гаснет, когда блок поставлен, или сама через 30 секунд.
Поля подсказка не заполняет. Когда все слоты заполнены, подсказывать нечего —
тогда светится «Проверить».

### Проверка

**«Проверить»** активна, когда заполнены все слоты. Подсвечиваются **все**
ошибки сразу:

| Вид | Значит |
|---|---|
| зелёный контур, ✓, «верно» | блок на месте |
| оранжевый пунктир, ≈, «почти» | перепутаны похожие строки |
| красная штриховка, ✕, «не здесь» | блок не на своём месте |
| у поля: «поле неверно», «проверь заглавные», «заполни поле» | ошибка в значении |

Когда всё верно, появляется окно с готовым кодом. **«Скопировать код»** кладёт
его в буфер обмена. Если копирование не сработало, код выделится, и хватит
нажать Ctrl+C. Дальше ученик вставляет код в Arduino IDE или PyCharm и
загружает на плату или запускает.

### Смена ученика

- **«В начало»** очищает сборку (с подтверждением) — для следующего ученика
  на том же этапе.
- **Логотип** возвращает к списку мастер-классов.
- Смена этапа в выпадающем списке тоже сбрасывает сборку. Если что-то уже
  поставлено, приложение спросит подтверждение.

Прогресс нигде не сохраняется. Закрыли вкладку — сборка пропала, это нормально.

## 11. Удаление и перенос мастер-классов

- **Удаление**: в списке админки наведите на мастер-класс и нажмите корзину.
  После подтверждения удаляются и файл `workshops/<id>.js`, и его строка в
  `index.html`. Отменить удаление нельзя. Для этого папка должна быть подключена.
- **Перенос на другой ноутбук**: скопируйте папку проекта целиком. Все
  мастер-классы лежат в `workshops/*.js` и подключены в `index.html`, больше
  нигде ничего не хранится.
- **Резервная копия** — копия той же папки. Если проект ведётся в git,
  изменения из админки видны как правки в `workshops/` и `index.html`.

## 12. Если что-то пошло не так

| Что случилось | Что делать |
|---|---|
| «Сохранить» и «Посмотреть как ученик» неактивны | Подключите папку проекта (раздел 3) или сохраните изменения |
| «В этой папке нет index.html и папки workshops» | Выбрана не та папка — выберите ту, где лежит `index.html` |
| Не даёт выбрать папку | Проект лежит прямо в «Документах»/«Рабочем столе» — переложите его во вложенную папку |
| Строки разобрались не той вложенностью | Нажмите «Выровнять отступы» и проверьте сводку под кодом |
| Закрывающая скобка попала в блоки | Она стоит на одной строке с кодом — вынесите её на отдельную строку |
| Мастер-класс не виден на главном экране | Файл не подключён в `index.html` — сохраните его из админки заново |
| Ученик видит старую версию | Изменения не сохранены или страница не перезагружена (F5) |
| Забыли пароль | Посмотрите `adminPassword` в `js/config.js` |

## 13. Для разработчика

- Сборки и зависимостей нет: ванильный JS, обычные `<script src>`, всё работает
  по `file://`. Правила проекта, модель данных и контракты ядра описаны в
  [`CLAUDE.md`](CLAUDE.md).
- Макеты экранов — `mockups/*.html`, открываются двойным кликом.
- Тесты — `tests.html`, открываются двойным кликом, результат печатается в
  страницу. Тесты ядра опираются на образец мастер-класса `tests/fixture.js`,
  поэтому правки контента в админке их не ломают. Подключённые мастер-классы
  проверяются только на соответствие модели.
- `tools/check-fs-access.html` проверяет, умеет ли браузер на этом компьютере
  записывать в папку.
