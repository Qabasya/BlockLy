# Локальная компиляция и загрузка на Arduino Nano

Для кнопки «Загрузить на плату» BlockLy собирает **текущий код ученика** в
прошивку с помощью Arduino CLI или Arduino IDE 1.8.19. Локальный сервер отдаёт приложение браузеру и
принимает код на `POST /api/compile`. Он работает только на `127.0.0.1` и сам
не обращается к последовательному порту. Порт открывает браузер после выбора
учеником платы в системном окне Web Serial.

## Подготовка компьютера

1. Установить Python 3.9 или новее. Существующую Arduino IDE 1.8.19 можно
   оставить; в ней должны быть пакет **Arduino AVR Boards** с опцией Nano
   **Old Bootloader** и библиотека **FastLED** в папке скетчей. Сервер сначала
   ищет Arduino CLI, а если её нет — `arduino_debug.exe` из Arduino IDE 1.8.19.
   Путь через IDE 1.8.19 ещё нужно проверить на учебном компьютере. На машине
   разработки проверена сборка через Arduino CLI 1.4.1 с Arduino AVR Boards
   1.8.8, FastLED 3.10.4 и avr-gcc 7.3.0-atmel3.6.1-arduino7.
2. Подключить Nano ATmega328P с пунктом **Old Bootloader**. Для другой платы
   этот способ сборки не предназначен.
3. На Windows положить папку `BlockLy` на рабочий стол. Рядом с ней положить
   `Start-BlockLy.bat` из архива релиза. Если папка скопирована без этого
   файла, внутри неё дважды щёлкнуть `Install-Desktop-Launcher.bat`.
   Перед занятием открыть `Start-BlockLy.bat`: он найдёт папку, запустит
   сервер и откроет Edge (или Chrome) по адресу `http://127.0.0.1:8765/`.
   Окно сервера должно оставаться открытым во время занятия.

Для ручного запуска из папки проекта: `python3 tools/serve.py --open-browser`
(на Windows также `py -3 tools\serve.py --open-browser`). Интернет после
установки компонентов не нужен.

Если IDE 1.8.19, CLI или FastLED находятся в нестандартных местах, можно задать
`BLOCKLY_ARDUINO_IDE1`, `BLOCKLY_ARDUINO_CLI` или `BLOCKLY_FASTLED`. Последняя
указывает на корень библиотеки с `src/FastLED.h`. Например:

```sh
BLOCKLY_ARDUINO_CLI=/путь/к/arduino-cli BLOCKLY_FASTLED=/путь/к/FastLED python3 tools/serve.py
```

Запуск двойным кликом по `index.html` по-прежнему подходит для обычных занятий
без прямой загрузки. Для компиляции нужен этот локальный сервер: браузер не
может запускать установленный компилятор Arduino напрямую. Старый скетч не
записывается на плату, пока ученик не выберет порт в браузере.

## API

`POST /api/compile` с `Content-Type: application/json` и телом
`{"code":"..."}`. Код ограничен 128 КБ. Успешный ответ:

```json
{"hex":":10000000...", "bytes":4560, "maxBytes":30720, "board":"arduino:avr:nano:cpu=atmega328old"}
```

`hex` — Intel HEX только программы, без загрузчика. При ошибке сервер
возвращает JSON `{"error":"..."}` и статус 4xx; сообщения компилятора
сохраняются. Для каждого запроса создаётся временный скетч, а после сборки
временные файлы удаляются. Сервер принимает запросы лишь с того же локального
адреса, откуда открыта страница.
