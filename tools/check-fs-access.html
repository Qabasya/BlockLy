Проверка: может ли страница записывать файлы

Открой этот файл двойным кликом в Chrome или Edge (адрес должен начинаться с file://), на том компьютере, где будет работать приложение. Нажимай кнопки по порядку.

Выбирай саму папку проекта (например, mk-blocks), а не «Рабочий стол», «Документы» или «Загрузки»: браузер их не разрешает. Тест создаёт только временные файлы _fs-test* и сам их удаляет.
