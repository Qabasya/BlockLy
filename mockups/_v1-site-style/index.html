2г. Образец состояний блокау каждого состояния своя форма контура и значок — цвет только усиливает

1. В палитре

Белый блок, серый контур, значок «+» слева. Ещё не поставлен.

#include <FastLED.h>

2. В слоте

Синяя заливка, сплошной контур 2 px, стрелки ↑↓ справа.

CRGB leds[NUM_LEDS];

3. Верный

Зелёная заливка, сплошной контур, значок ✓ и подпись «верно».

FastLED.show();верно

4. Почти верный

Жёлтая заливка, пунктирный контур, значок ≈. Различия подсвечены и подчёркнуты — в блоке и в его двойнике.

leds[1] = CRGB::Red;почти
а нужна близкая строка:
leds[0] = CRGB::Red;

Пример пары-близнецов взят из другого этапа: в этапе «Зажечь ленту белым» таких строк нет.

5. Неверный

Красная штриховка, толстый контур 3 px, значок ✕ и подпись.

FastLED.show();не здесь

6. Подсвечен подсказкой

Двойной синий контур, значок «?». Подсвечены блок в палитре и его слот.

#define POT A0
Сюда встанет этот блок

7. Слот пустой

Пунктирный серый контур, без заливки, курсивная подпись.

Пустой слот — кликни по блоку справа

8. Хвост

Серая плашка без контура, значок замка. Появляется сама вместе с открывающим блоком, не берётся и не двигается.

void setup() {
}

fill_solid(leds, NUM_LEDS, CRGB::White);
